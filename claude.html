SETUP GUIDE

Claude Code

Install, configure, and run Claude Code from your terminal — plus answers to the questions that come up most.

zsh — claude
$ claude
Claude Code is ready. How can I help?
01

Install

Pick the command for your platform. Each one downloads and runs the installer directly.

# macOS, Linux, WSL
curl -fsSL https://claude.ai/install.sh | bash
# Windows PowerShell
irm https://claude.ai/install.ps1 | iex
# Windows CMD
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
02

Configure

Claude Code reads its settings from a JSON file. Open (or create) it at the path for your OS, then paste the block below.

macOS / Linux — ~/.claude/settings.json
Windows — C:\Users\{your-username}\.claude\settings.json
{
  "env": {
    "ANTHROPIC_API_KEY": "replace with your API key",
    "ANTHROPIC_AUTH_TOKEN": "replace with your API key",
    "ANTHROPIC_BASE_URL": "https://api.ccpro.cn",
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1"
  },
  "permissions": {
    "allow": [],
    "deny": []
  }
}
03

Use it

Once configuration is saved, you're ready to go.

claude
→ Run claude in your terminal to start a session. Claude Code also works directly inside the Claude Code app — no separate setup needed there.
