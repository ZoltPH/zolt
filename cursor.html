Step 0

Read this first — save 90% of your time

Most install failures come from one of two things: an outdated Cursor, or missing admin rights. Skipping this section is the #1 reason the plugin won't activate.

!

Important — don't run multiple agents at once

The upstream server is tightening its API-key monitoring. If you run 2–3 Cursor agents in parallel on the same prompt, your key will be detected quickly, hit its daily quota, and in severe cases the key may be locked and your device blocked. Locked keys cannot be restored. Use one agent per session.

1

Cursor is new — install normally

First time installing Cursor? Skip this warning. Install it like any other app.

2

Cursor is old — uninstall first, then reinstall

If you already have an old Cursor, uninstall it first — don't install over it. This avoids 99% of errors.

3

Install into the default folder

macOS: /Applications. Windows: C:\Users\<you>\AppData\Local\Programs. Other folders need manual permissions.

Step 1

Pick the right version

Cursor 3.0 changed the UI significantly, so the extension ships in two tracks. Match the track to your Cursor version and activation is smooth.

Extension 2.8.x → Cursor 3.9 – 3.14

Download Cursor 3.9 through 3.14 from the official site. Windows: pick System x64. macOS: pick Mac Universal. Linux: pick .AppImage.

Extension 2.9.x → Cursor 3.15 and above

The latest line, fully compatible with the Agents Window and modern Cursor builds. Recommended if you're installing fresh.

Step 2

Install the plugin into Cursor

Three sub-steps and you're done. Open Cursor with admin rights first — without them, the extension can't write the patches it needs.

A

Switch back to the classic Editor view (required from Cursor 3.0)

Cursor 3.0 introduces the Agents Window — the plugin cannot be installed from inside it. Switch back to the classic Editor using any of these:

  • Press Ctrl+Shift+N (Windows / Linux) or ⌘+Shift+N (macOS)
  • Click the Editor icon in the top-right corner
  • Open the menu File → Open Editor Window
i
Once the plugin is installed, you can switch back to the Agents Window if you prefer. The plugin only can't be installed there.
The same five-button welcome panel from the hero appears here too, this time with a small overlay in the top-right corner pointing at an Editor icon. The overlay reads something like "Click here to switch back to the classic Editor view". After you click, the window reloads into the familiar Cursor editor — sidebar on the left, file tree, tabs along the top. From here you can install extensions normally.

C

Install the extension from a .vsix file

The plugin ships as a .vsix file. Install it directly (not via the Marketplace).

Press Ctrl+Shift+P to open the Command Palette, then type VSIX
  1. Pick Extensions: Install from VSIX… from the list.
  2. Browse to the .vsix file you downloaded → click Open / Install.
  3. Wait for Cursor to show "Completed Installing" — the extension appears in the Extensions sidebar.

Command Palette view — A wide text input drops down from the top-center of the window with the placeholder "Type a command to run". Once you type VSIX, three matching commands appear below the input. The first one — Extensions: Install from VSIX… — is highlighted as the top match (slight blue background, the file-extension icon to its left).

Inside the file list you'll see your .vsix file — clicking it highlights it blue and populates the File name field at the bottom with its full path. The action button at the bottom-right reads Open; click it and Cursor begins the install, then briefly shows a small loading spinner in the bottom-right corner.

Appendix

Install Cursor on Linux (AppImage)

If you're on Linux, here's how to install Cursor from a .AppImage without a package manager.

1

Change to your Downloads folder

cd ~/Downloads
2

Make the AppImage executable

chmod +x Cursor-2.6.11-x86_64.AppImage
3

Run Cursor (the safe way)

# --appimage-extract-and-run : run without FUSE
# --no-sandbox            : disable Chromium sandbox (avoids permission errors on some distros)
./Cursor-2.6.11-x86_64.AppImage --appimage-extract-and-run --no-sandbox
i
Replace Cursor-2.6.11-x86_64.AppImage with the exact filename you downloaded. Use Tab to autocomplete.

Tip

Fix Cursor replying in the wrong language

If the Agent replies in a language you didn't ask for, add a Project Rule to force the language you want.

1

Open Rules and Commands

Go to Cursor Settings → Rules and Commands.

2

Create a Project Rule

In the Rules section, click New → Project rules.

In the Settings page, scroll to the Rules section header. On its right edge sits a button labelled New with a small downward chevron — clicking it opens a slim dropdown menu listing three options. The second option — Project rules — is what you want; picking it scopes the rule to the current project only (instead of all your projects). A red marker overlay in the docs highlights this exact entry.
3

Name it and write the rule

Give it a name (e.g. language-en) and paste the rule below:

Always respond in English. Match the user's input language only when explicitly asked; otherwise default to English for code comments and explanations.

Editor view — The rule editor is a two-field form. The top field is a small single-line input where you type the rule's name (language-en in this case). Below it is a larger multi-line text area with a slight monospace feel — paste your rule text here. A character count sits in the bottom-right corner of the textarea. Hit ⌘+S / Ctrl+S to save; the editor collapses back into the list.

List view — Back in Settings → Rules and Commands, the new language-en rule now appears at the top of the Rules list with a small teal Active badge on its right. Pre-existing rules (if any) sit below it, each with their own toggle and edit pencil.

Troubleshooting

When something doesn't work

Try the three steps below in order. In most cases, one of them will fix the problem.

!
The "99% fix" — try these in order:
  1. Quit Cursor completely and reopen it.
  2. Still broken? Open Cursor as Admin (revisit Step 2).
  3. Still broken? Uninstall and reinstall Cursor into the default folder.
Permission denied — can't create / edit / backup files

This happens when Cursor can't write into its install directory or the project folder. The fix depends on your OS:

🪟 Windows
  1. Option 1: Launch Cursor via Run as administrator (see Step 2B).
  2. Option 2: When Cursor prompts "permission denied", click Cancel, quit Cursor completely, then reopen as admin.
  3. Option 3: Uninstall Cursor completely and reinstall into the default folder C:\Users\<you>\AppData\Local\Programs.
🍎 macOS
  1. Option 1: Take ownership of Cursor's app folder:
# Change ownership to the current user
sudo chown -R `whoami` /Applications/Cursor.app/Contents/Resources/app
  1. Option 2: Launch Cursor directly from Terminal as root:
sudo /Applications/Cursor.app/Contents/MacOS/Cursor

If it still errors, open Terminal via Right-click → Open → Open to bypass Gatekeeper.

🐧 Ubuntu / Linux
  1. Change ownership of the install directory:
# Replace /opt/cursor with the actual path on your system
sudo chown -R `whoami` /opt/cursor
  1. Or run the AppImage directly (see the Linux section above).
Webview failed to load — blank screen / hang

This is caused by a corrupted webview cache. Clear it and restart:

Method 1 — Task Manager
  1. Press Ctrl+Shift+Esc to open Task Manager.
  2. Find and End task any processes named Cursor.
  3. Reopen Cursor.
Method 2 — Clear Service Worker cache
  1. Quit Cursor completely.
  2. Press Win+R, type %APPDATA%\Cursor\Service Worker → Enter.
  3. A File Explorer window opens — delete the entire Service Worker folder inside.
  4. Reopen Cursor.
Zolt PH icon missing from the sidebar

After install, the icon can be hidden by another view. Bring it back:

  1. Right-click the Activity Bar (the vertical strip on the left).
  2. Untick Compact Menu if it's enabled.
  3. Or go to View → Appearance → Activity Bar Position to restore the default position.

If it still doesn't show, open the Extensions panel (Ctrl+Shift+X), find Zolt PH in the list, and click Reload.

Key is valid but the plugin says "activation failed"

Common causes:

  • Your system clock is significantly off. Check Date & Time in Settings.
  • A VPN or proxy is blocking the activation endpoint. Disable it for a minute and try again.
  • The key has already been used on another machine. Message admin with a screenshot to request a replacement.
