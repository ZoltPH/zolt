01

Install

Use the desktop app, or install the CLI if you'd rather work from the terminal.

Desktop app

Download and install the app directly:

Official download Mirror download

CLI (optional)

To use Codex from the command line instead, make sure Node.js is installed first, then run:

# 1. Install globally
npm install -g @openai/codex
# 2. Confirm the install worked — a version number means you're set
codex --version
02

Configure

Run the install command for your platform, then paste in your API key when prompted.

# macOS / Linux
curl -fsSL https://ccpro.cn/install/codex/codex-config-api.sh | bash
# Windows PowerShell
irm https://ccpro.cn/install/codex/codex-config-api.ps1 | iex
# Windows CMD
curl -fsSL http://ccpro.cn/install/codex/codex-config-api.bat -o "%TEMP%\codex-config.bat"

Pick the command for your platform, copy it, and press enter to run it. When you see Enter your API Key, paste in your purchased key (starts with sk-jy-ex) and press enter.

! Never share your full key with anyone, and never post it publicly. If you need help verifying it, share only the last six characters.
Setting up manually instead? Set base_url to https://api.ccpro.cn/v1

03

Use it

Once configuration is complete, you're ready to go.

codex
→ Restart the app, or run codex directly in your terminal, to start using it.

Image generation

Download the image-generation skill, then drag the zip file into the Codex chat window:

ccpro-image-generator.zip

Send this message to the Codex client, swapping in your own key:

Install this skill globally in Codex, and set the
IMAGE_CURL_NODE_API_KEY environment variable in this
skill's .env file to [your key here].

To generate an image afterward, just run /ccpro-image-generator in the Codex client, then describe what you want.

04

Troubleshooting

Common errors and what to do about each one.

View current usage against your key here:

ccpro.cn/key-usage

This is almost always a local network issue — the server side is running normally. Try these in order:

  1. Switch to a different network
  2. Turn on your VPN in global / TUN mode
  3. Switch nodes, then try again
Failed · unexpected status 400 Bad Request
{"error":{"message":"The encrypted content gAAA...V5w= could not be verified. Reason: Encrypted content could not be decrypted or parsed.","type":"invalid_request_error"}}

Fastest fix: start a new session.

If you need to keep your existing context, this generally traces back to how session files handle certain properties across app restarts — check the community thread linked from your source for the current workaround, since the fix has moved between versions.

Known upstream issue: the instructions field gets dropped when context.systemPrompt is undefined. Tracked in the openai-codex issue tracker — check there for the current status and workaround.

401 Unauthorized
Incorrect API key provided: sk-jy-cx...

You'll need to run through the Configure step again.

503 Service Unavailable
stream disconnected before completion: error sending request for url

This is a local network issue. Retry, or work through the Reconnecting… steps above.

429
exceeded retry limit, last status: 429 Too Many Requests

Check your key's remaining quota to see whether it's been used up.
